# Invent a Word We Need

One new English word and its one-line definition, for make.fun's `u-deranalabs-invent-a-word-we-need-17a020e0` bounty.

The entry: *"ghostping — the notification that vanishes the second you swipe down to read it."* (80 characters)

The field is laughlag, lockdoubt, songslip, and Unwave — all names for small daily moments. This one names a moment that genuinely has no name yet: the notification that disappears the instant you go to read it. The word is a clean blend (ghost + ping), and the definition is the exact experience, in one breath. The ghost is the point: the ping was real, you saw it, and by the time you reach for it there is nothing to open.

`main.ts` (Node 22, stdlib only) writes the word and definition to `/output/entry.txt`, deterministically.
